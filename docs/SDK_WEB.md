Naming rule (spec has no `operationId`s, so Orval derives names from method+path): `use` + Method + Path, e.g. `POST /api/Posts` → `usePostApiPosts`; `GET /api/Posts/feed` → `useGetApiPostsFeed`. Two emission shapes exist in this repo — check the signature before use:
- **Body-carrying writes** (`POST/PUT/DELETE` with a JSON body) are emitted as **`useQuery`-style overloaded functions**: `usePostApiPosts(body, options?, queryClient?)` (`posts.ts:104-139`), same for `usePostApiUserSignIn`, `usePutApiPosts`, `useDeleteApiPostsPostId`. For fire-on-submit forms, wrap the raw fetcher (`postApiPosts`) in your own `useMutation` (§3.2).
- **Param-only GETs** (feed, my-posts, profile, search, likes) are emitted as **`useMutation` hooks**: `useGetApiPostsFeed(options?, queryClient?)` with variables `{ params }` (`posts.ts:459-502`). Paginate via `mutate({ params: { Page, Limit } })` (§3.1).
Each endpoint file also exports the raw fetcher (`postApiPosts`, `getApiPostsFeed`), `get…QueryKey` / `get…MutationKey`, and `get…QueryOptions` / `get…MutationOptions`.

### 2.2 Auth & transport (`sdks/generator/custom-instance.ts`)

Copy this file into your app (it is the committed mutator source; generated hooks import it):

```typescript
import axios, { type AxiosRequestConfig } from 'axios';

const AXIOS_INSTANCE = axios.create({
  baseURL: process.env.NEXT_PUBLIC_API_URL || 'http://localhost:5000',
});

AXIOS_INSTANCE.interceptors.request.use((config) => {
  if (typeof window !== 'undefined') {
    const token =
      localStorage.getItem('access_token') ?? sessionStorage.getItem('access_token');
    if (token) config.headers.Authorization = `Bearer ${token}`;
  }
  return config;
});

// Orval forwards react-query's AbortSignal inside `config` —
// cancellation works natively; no axios CancelToken anywhere.
export const customInstance = <T>(
  config: AxiosRequestConfig,
  options?: AxiosRequestConfig,
): Promise<T> =>
  AXIOS_INSTANCE({ ...config, ...options }).then(({ data }) => data);

export type ErrorType<E = unknown> = E;   // narrow per-call as AxiosError<ApiResponse>
export type BodyType<B = unknown> = B;
```

Set `NEXT_PUBLIC_API_URL` (e.g. `https://social-api-v1.runasp.net`). Store the JWT from `usePostApiUserSignIn` under `access_token`; clear it on logout / 401.

## 3. Usage recipes

### 3.1 Data fetching — feed page (GET-as-mutation pattern)

Feed/my-posts/profile endpoints are emitted as **mutations** (`useGetApiPostsFeed`, key `['getApiPostsFeed']`), because the spec declares `Page`/`Limit` as optional query params on GETs and Orval maps them to mutation options. Paginate explicitly and invalidate on writes:

> **Typing caveat (verified):** every fetcher is typed `customInstance<void>` because the spec declares no response schemas — `feed.data` is `void` at the type level even though the wire body is the `ApiResponse` envelope (§1.2 of `API_REFERENCE.md`). Cast through your own envelope type:

```typescript
type Envelope<T> = { success: boolean; message: string; data: T; errors: null };
```

```tsx
import { useGetApiPostsFeed } from '@/sdk/endpoints/posts/posts';

function Feed({ page }: { page: number }) {
  const feed = useGetApiPostsFeed();
  // trigger (e.g. in useEffect on [page]):
  // feed.mutate({ params: { Page: page, Limit: 20 } });
  if (feed.isPending) return <p>Loading…</p>;
  if (feed.isError) return <ApiError error={feed.error} />;
  const posts = (feed.data as unknown as Envelope<unknown[]> | undefined)?.data ?? [];
  return <>{posts.map((p) => <PostCard key={(p as { id: string }).id} post={p} />)}</>;
}
```

```typescript
// cache invalidation after any post write
import { useQueryClient } from '@tanstack/react-query';
const qc = useQueryClient();
qc.invalidateQueries({ queryKey: ['getApiPostsFeed'] });
```

Query-style hooks forward react-query's `AbortSignal` into Axios (`posts.ts:60-67,91`):

```typescript
export const postApiPosts = (body, options?, signal?: AbortSignal) =>
  customInstance({ url: '/api/Posts', method: 'POST', data: body, signal }, options);
// posts.ts:91
const queryFn: QueryFunction<…> = ({ signal }) =>
  postApiPosts(createPostRequest, requestOptions, signal);
```

Unmounted components therefore cancel in-flight requests automatically — no `CancelToken` anywhere.

### 3.2 Mutations — create post (raw fetcher in your own `useMutation`)

`usePostApiPosts` is query-style (it takes the body up front), so submit-forms wrap the raw fetcher instead:

```tsx
import { useMutation, useQueryClient } from '@tanstack/react-query';
import { postApiPosts } from '@/sdk/endpoints/posts/posts';
import type { CreatePostRequest } from '@/sdk/models';

function Composer() {
  const qc = useQueryClient();
  const create = useMutation({
    mutationFn: (body: CreatePostRequest) => postApiPosts(body),
    onSuccess: () => qc.invalidateQueries({ queryKey: ['getApiPostsFeed'] }),
    onError: (e) => toast.error(apiMessage(e)),
  });
  // create.mutate({ title, content, visibility: 'Public', media });
}
```

### 3.4 Error handling — one standard shape

Every failure is an `AxiosError` wrapping the `ApiResponse` envelope (`{ success, message, data, errors }`):

```typescript
import { isAxiosError } from 'axios';

export function apiMessage(e: unknown): string {
  if (isAxiosError<{ message?: string; errors?: { field: string; error: string }[] }>(e)) {
    const d = e.response?.data;
    if (d?.errors?.length) return d.errors.map((x) => `${x.field}: ${x.error}`).join('; ');
    return d?.message ?? e.message;
  }
  return 'Something went wrong. Please try again.';
}

// usage: if (isAxiosError(e) && e.response?.status === 401) { clearToken(); redirectToLogin(); }
```

Status map: 400 validation/share-policy/block-gates · 401 expired-or-revoked/blocked-read · 403 non-admin on `/api/admin/**` · 404 missing-or-deleted · 500 unexpected.
